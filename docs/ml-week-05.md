## День 2. Матрица как преобразование (2 ч)
- 3Blue1Brown, главы 3–5.
- Столбцы матрицы — это то, куда переходят базисные векторы.
- Умножение матриц как композиция преобразований; почему `A @ B` не равно `B @ A`.
- Упражнение: применить к сетке точек поворот, растяжение и сдвиг, нарисовать результат; сравнить порядок `R @ S` и `S @ R`.

## День 3. Определитель, ранг, системы уравнений (2 ч)
- 3Blue1Brown, главы 6–8.
- Определитель — во сколько раз меняется площадь или объём; `det = 0` означает схлопывание пространства.
- Ранг, обратная матрица, `Ax = b` как поиск вектора, который перейдёт в `b`.
- Упражнение: создать матрицу с линейно зависимыми столбцами, проверить `np.linalg.matrix_rank` и `det`, посмотреть, что вернёт `np.linalg.solve`.

## День 4. Скалярное произведение и проекции (2 ч)
- 3Blue1Brown, главы 9–10.
- Скалярное произведение как мера сонаправленности; связь с `cosine_similarity` из `vecops.py`.
- Проекция на вектор: `proj = (a @ u) / (u @ u) * u`. Проекция на подпространство столбцов `A`: `P = A @ inv(A.T @ A) @ A.T` (в коде — через `solve`).
- Метод наименьших квадратов как проекция `y` на столбцы `X` — это линейная регрессия с 9-й недели.
- Упражнение: спроецировать облако 2D-точек на прямую, проверить, что остаток ортогонален прямой, а `P @ P` совпадает с `P`.

## День 5. Собственные векторы и SVD (2 ч)
- 3Blue1Brown, глава 14. Справочно: [Mathematics for Machine Learning](https://mml-book.github.io/), разделы 4.2 и 4.5.
- Собственный вектор не меняет направления: `A v = λ v`.
- Ковариационная матрица: `C = X.T @ X / (n - 1)` для центрированных данных; её собственные векторы — направления наибольшего разброса.
- SVD: `X = U Σ Vᵀ`, связь с собственными значениями: `λ = σ² / (n - 1)`.
- Упражнение: для данных с корреляцией найти собственные векторы `C` через `np.linalg.eigh`, нарисовать их поверх облака точек.

## Как математика записывается в numpy

| Математика | numpy | Подвох |
|---|---|---|
| `Ax` | `A @ x` | `A * x` — поэлементно или broadcasting, ошибки может не быть |
| `Aᵀ` | `A.T` | у вектора формы `(n,)` транспонирование ничего не меняет |
| `A⁻¹b` | `np.linalg.solve(A, b)` | `inv` медленнее и менее точен |
| `‖x‖` | `np.linalg.norm(x)` | для матрицы по умолчанию норма Фробениуса, нужна `axis=` |
| Собственные значения симметричной матрицы | `np.linalg.eigh` | идут по возрастанию; `eig` их не сортирует |
| SVD | `np.linalg.svd` | возвращает `Vᵀ`, а не `V`; `S` — одномерный массив |
| Знак компоненты PCA | любой | `v` и `-v` равноправны, поэтому сравнивать надо с точностью до знака |
